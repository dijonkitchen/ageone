# SPEC-0001: Agent Todo Repo

## Functional requirements

Ensure foundation of a monorepo for agentic projects is setup.

Basics include simple text files that define specs and related decisions for potentially many projects in the future.

Priority list of organized specs.

Various people or agents can add to specs and priorities are adjusted on a regular basis.

Agents always have something to work on.
E.g., highest priority spec, reprioritizing specs, or generating new specs.

## Non-functional requirements

Easily portable, refactorable, and maintainable by both people and agents.

## Definition of done

Have a list of priorities that can be added to and updated.
